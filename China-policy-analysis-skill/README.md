# 中国政策风险分析 Skill

[English](README.en.md)

> 这是 Cliff-skill 集合中的模块副本。以下相对路径与命令均以 `China-policy-analysis-skill/` 为工作目录；历史来源见集合根目录的迁移清单。

面向中国政策与宏观金融问题的结构化分析方法。它将公开政策文本、资金约束、执行激励和统计证据组织成可检验的传导链，最终讨论对居民就业、现金流、负债与资产的影响。

本仓库交付的是 Agent 指令与参考方法，不是已校准的政策预测模型。分析质量取决于数据、识别假设和宿主模型；没有充分证据时应保留未知或竞争解释。

## 方法与范围

| 分析问题 | 核验重点 |
| --- | --- |
| 政策目标与执行 | 资金来源、实施细则、责任主体、地方能力和配套缺口 |
| 成本与风险转移 | 中央、地方、金融机构、企业、居民的约束及退出选择 |
| 宏观金融压力 | 汇率、房地产、地方债、银行、就业与资本流动的传导 |
| 官方数据一致性 | 同口径分项、价格/数量、地区与所有制、版本和发布滞后 |
| 居民行动 | 适用条件、不可逆损失、分阶段行动及后续验证 |

政策文件表述与实际结果分别记录。统计矛盾优先检查口径、修订、基期、滞后、结构分化和样本偏差，再用财政、用电、物流、企业现金流和贸易伙伴数据交叉检验；不能直接把矛盾解释为虚假。缺少识别依据时，不把相关性或主体动机当作因果结论。

## 使用

将本仓库中包含 `SKILL.md`、`references/` 与 `agents/` 的目录安装到宿主支持的 Skill 目录，然后明确调用：

```text
使用 $china-policy-risk-analysis 分析这项政策的执行条件、
资金与风险传导、官方数据一致性，以及普通居民的行动边界。
```

输出应先给核心判断与证据强度，再列传导机制、支持与反对证据、居民行动条件和下一验证点。不要为每个问题强制展开所有专题。
