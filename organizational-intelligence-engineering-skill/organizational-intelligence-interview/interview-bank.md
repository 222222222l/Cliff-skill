# 智能组织相关岗位面试题库 v0.1
## 第一性原理与组织
1. 为什么五个顶尖模型做大型项目可能比一个模型更贵更差？如何分离任务难度与协调损耗？
2. Competence、Coordination、Mosaic Intelligence 如何转成可测指标？
3. 如何根据任务依赖密度调整团队规模？什么情况下撤销 Agent？
4. 什么时候选脚本、确定性流程、单 Agent、固定多 Agent、自适应多 Agent？
5. 规模弹性高于 1 是否意味着无限扩张？有限实验如何验证？
## 任务状态与架构
6. 设计一个支持持久化、超时重试、人工审批的长任务状态机。
7. Supervisor 和去中心化组织各适合什么任务？
8. Agent A 持有 revision=17，Agent B 更新到 revision=18，如何防止旧信息覆盖新状态？
9. 为什么向量数据库不能成为权限与业务状态的唯一事实来源？
10. MCP、A2A、工具调用的边界是什么？
## 可靠性与安全
11. Agent 自称完成，但验证失败，如何防止错误状态被当作 accepted？
12. 超时后不确定工单是否写回，如何通过幂等键、对账和补偿处理？
13. 多 Agent 共用代码库如何隔离写入和集成？
14. 如何阻止提示词注入让 Agent 变更权限或执行越权动作？
## 评测和经济性
15. goodput、throughput、token/sec 对购买方的意义差异是什么？
16. 设计单 Agent 与多 Agent 的预算固定、任务配对的消融实验。
17. 重复阅读、通信、重试、人工纠错分别怎样归因成本？
18. 一组实验零任务成功，如何报告每个合格任务的成本？
## 工业 AI 和产品
19. 设计传感器异常→证据→处置方案→审批→CMMS 写回→确认的闭环。
20. 工厂已有 MES/ERP/CMMS 时，新增智能组织层应该拥有哪部分职责？
21. 如何让幻觉根因不触发危险设备动作？
22. 生产主管不愿意用系统，如何访谈、试点和测量采用率？
23. 如何向面试官解释模拟数据与生产真实收益之间的边界？
24. 如何应对“作品是 AI 生成的，所以并不能证明你的能力”的质疑？
