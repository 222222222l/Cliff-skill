# 智能组织工程与 Agent 平台岗位八周学习路径

目标：20分钟完整讲解工业 Agent 产品的真实业务链路、单/多 Agent 取舍、任务图、状态管理、权限、人工审批、幂等写回、故障恢复、Eval/FinOps，并能现场调试一个演示系统。

| 周次 | 重点 | 可验收交付 |
|---|---|---|
| 1 | 交易成本、有限理性、Mosaic Intelligence、规模收益 | 单 Agent 基线与任务依赖图 |
| 2 | Workflow、DAG、Supervisor、任务切分、关键路径 | 含异常分支和人工审批的状态图 |
| 3 | 共享状态、事件日志、组织记忆、版本冲突 | 双 Agent 冲突复盘 |
| 4 | MCP、A2A、权限、审计、幂等、恢复 | 模拟 CMMS 工单重复写入防护 |
| 5 | Agent Eval、goodput、消融、全部成本归因 | OrgBench 对照报告 |
| 6 | 工厂 MES/ERP/CMMS、异常与维修流程 | FactoryOps PRD 与可交互 Demo |
| 7 | 自适应调度、组织重组、ROI 取舍 | 一篇拒绝不必要多 Agent 的 ADR |
| 8 | 产品、架构、工程、业务四轮模拟面试 | 20分钟录屏、复盘与弱项矩阵 |

练习协议：每次一题 → 用户作答 → 评估准确部分与缺口 → 最多两轮追问 → 评分与练习。每点掌握度 0未知、1认识概念、2能推导、3能设计、4有真实证据。两周复测。固定基线和已验收项目事实不可被模型总结替代。
