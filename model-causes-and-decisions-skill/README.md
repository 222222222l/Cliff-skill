# 因果与决策建模 Skill

[English](README.en.md)

> 这是 Cliff-skill 集合中的模块副本。以下相对路径与命令均以 `model-causes-and-decisions-skill/` 为工作目录；历史来源见集合根目录的迁移清单。

`model-causes-and-decisions` 将现象、归因、预测与行动选择转化为明确的系统模型：定义对象、反事实、竞争假设、识别条件、不确定性和决策规则。

本仓库提供方法指令与评估案例，没有把这些方法包装成自动发现因果关系的软件或已验证的预测器。

## 分析流程

1. 固定决策、目标变量、分析单位、期限、损失与行动约束。
2. 建立主体—激励—行动—状态/流量—反馈结构。
3. 写出基线、主要解释与至少一个竞争假设，以及能区分它们的证据。
4. 检查时序、测量、混杂、共同支持、预期、溢出和样本选择。
5. 选择最小充分方法，进行稳健性/敏感性验证，再定义行动与停止条件。

方法参考包括变点、事件研究/中断时间序列、双重差分、DAG/结构因果模型、模型归因、全局敏感性、部分识别、贝叶斯更新和信息价值。方法复杂度应由问题和数据决定。

## 声明边界

| 层级 | 可支持的声明 |
| --- | --- |
| I0 | 叙事或情景 |
| I1 | 描述或会计差异 |
| I2 | 相关、预测或模型归因 |
| I3 | 明确识别假设下的因果估计 |
| I4 | 经过稳健性、机制或复现支持的因果估计 |

公式使假设明确，不使假设自动成立。SHAP、回归系数、异常差值和相关性不能直接当作因果贡献；没有会计恒等式或声明的分解，也不强制贡献相加为100%。

## 安装与调用

将 `model-causes-and-decisions/` 安装到宿主支持的 Skill 目录。

```text
使用 $model-causes-and-decisions 对该现象建模，区分可观察事实、
假设与情景，并给出识别条件、竞争解释和行动规则。
```

当前 Skill 明确区分调用模式：用户明确请求建模时执行请求范围；仅判断适用、未收到建模请求时，只推荐一种主方法和最多一种备选，不自行展开完整归因。方法选择请求也不自动扩成完整研究。
