# Output Contract

Use this reference for structured, long-form, or multi-module answers. Match the
user's language and lead with the conclusion.

## Core Answer

Include only fields that affect the decision:

1. **Scope and data**: target, market, as-of time, frequency/range, horizon,
   freshness, adjustment status, and material gaps.
2. **Current state**: regime, trend stage, valuation/fundamental state,
   liquidity/flow state, and crowding when relevant.
3. **Causal read**: driver -> transmission -> observable market variable ->
   price/earnings effect.
4. **Evidence balance**: strongest independent supporting evidence and
   strongest opposing evidence. Do not list every computed indicator.
5. **Probabilistic scenarios**: base, upside, and downside path with horizon,
   range, catalyst, probability type, and confidence.
6. **Decision boundaries**: key price levels or time windows, confirmation,
   invalidation, and what new evidence would change the view.
7. **Risk note**: event, liquidity, leverage, gap, transaction-cost, or
   data-quality risk that could dominate the forecast.

## Evidence Labels

Separate evidence by epistemic status:

| Label | Meaning |
| --- | --- |
| Verified observation | Directly supported by dated price, filing, official release, primary source, or structured data. |
| Estimate | Derived value with assumptions or a plausible range. Show the key assumption. |
| Inference | Interpretation from observations and a stated causal mechanism. |
| Scenario assumption | Unverified condition used to test a future path. Do not present it as fact. |

Use an evidence grade when source quality matters: `A` primary/current/complete,
`B` credible but partial or lagged, `C` secondary or materially incomplete,
`D` anecdotal/unverified.

## Probability Labels

- **Empirical probability**: calibrated from a defined historical sample with
  out-of-sample or walk-forward validation.
- **Model-implied probability**: generated by a disclosed scoring/model rule;
  not a historical frequency claim.
- **Scenario weight**: judgmental Bayesian allocation across paths. Use when
  calibration data is insufficient.

Never mix these labels. If data is insufficient, do not fabricate a number:

```text
Current evidence supports only a low-confidence directional conclusion, not a
reliable numeric probability. Missing data: ...
```

## Conflict and Falsification

- Preserve conflicts across horizons instead of averaging them away.
- Name the strongest alternative explanation.
- State two to four observable conditions that would falsify or materially
  downgrade the preferred view.
- Distinguish an early warning from formal confirmation and a delayed buffer
  from a bullish catalyst.
